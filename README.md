I developed a simple ASP.NET MVC project to understand the difference between direct dependency and dependency injection. Initially, I used direct dependency by creating objects manually inside the controller, which led to tight coupling. Then, I introduced an interface and implemented it in a separate class library to separate logic from usage. I configured dependency injection in the Program.cs file to map the interface to its implementation. Using constructor injection, the controller now receives the required object automatically instead of creating it. This approach improved flexibility, maintainability, and followed industry best practices like IoC and loose coupling.
